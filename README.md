# Higher-Level Programming (Python)

**Python from first principles to a REST API: data structures, object-oriented programming, tests, files, serialization.**

Holberton School × Tuwaiq Academy, Advanced Software Engineering track. Each folder is one project with numbered tasks.

| Folder | What it covers |
|---|---|
| `python-hello_world` | Printing, strings, the interpreter |
| `python-if_else_loops_functions` | Control flow and functions |
| `python-import_modules` | Modules, imports, command-line arguments |
| `python-data_structures` | Lists and tuples |
| `python-more_data_structures` | Sets, dictionaries, lambda, map, filter |
| `python-exceptions` | Raising and handling exceptions |
| `python-classes` | Classes, attributes, properties |
| `python-more_classes` | Special methods, class attributes |
| `python-test_driven_development` | Doctests and unit tests |
| `python-inheritance` | Inheritance and method lookup |
| `python-abc` | Abstract base classes, interfaces |
| `python-input_output` | Files and JSON |
| `python-serialization` | Serializing and deserializing data |
| `restful-api` | HTTP, building a REST API |

Python 3 · PEP 8 (pycodestyle) · tested on Ubuntu
